## 远程仓库操作示例

在 GitHub/Gitee 网页创建一个空仓库（不要自动生成 README），复制该仓库的 HTTPS 地址。打开本项目目录的 PowerShell：

```powershell
git status
git remote add origin 你自己的仓库HTTPS地址
git push -u origin HEAD:main
```

如果从 ZIP 解压、目录中没有 `.git`，先执行：

```powershell
git init -b main
git add .
git commit -m "Initial campus lost-found agent"
```

首次提交若要求身份，按 Git 提示配置你自己的 name/email。请不要把示例占位符原样用作真实地址，也不要将访问令牌放进仓库文件。
